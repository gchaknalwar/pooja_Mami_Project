# 📋 Online Project Management System

A modern and responsive **Online Project Management System** built using **React.js** and **Vite**. This application helps teams organize projects, manage tasks, monitor progress, and improve collaboration through an intuitive and user-friendly interface.

---

## ✨ Features

### 📁 Project Management

- Create New Projects
- View Project Details
- Update Existing Projects
- Delete Projects
- Organize Multiple Projects

---

### ✅ Task Management

- Create Tasks
- Assign Tasks
- Update Task Status
- Track Progress
- Manage Deadlines

---

### 👥 Team Collaboration

- Team Member Management
- Project Assignment
- Task Monitoring
- Progress Tracking

---

### 🎨 User Interface

- Modern & Clean UI
- Responsive Design
- Fast Navigation
- Reusable React Components
- Optimized Layout

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/gchaknalwar/Online-Project-Management-System.git
```

### Navigate to the Project

```bash
cd Online-Project-Management-System
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
